# 课表配色变化原因排查

## Goal

只读定位上个版本与当前课表配色差异的代码来源，并厘清它与手机端导入 PR 的关系。本任务不恢复配色、不修改产品代码。

## Requirements

- 对比当前主线和改色提交的父版本，确认课程卡片背景、文字与非本周课程配色的差异。
- 核对配色分配算法是否变化，以及是否会改变课程与色板的对应关系。
- 核对改色提交与手机端导入 PR 的提交顺序及文件范围。

## Acceptance Criteria

- [x] 找到直接改动课表配色的提交，并说明其对卡片背景和文字颜色的影响。
- [x] 说明课程到色板的映射算法是否变化。
- [x] 用提交祖先关系和 PR 文件清单判断手机端导入 PR 是否引入了课表配色改动。
- [x] 将证据和时间线记录在 `research/root-cause.md`，不改产品代码。

## Notes

- 若用户后续要求恢复目标配色，应另行确认恢复范围并建立实现任务。
