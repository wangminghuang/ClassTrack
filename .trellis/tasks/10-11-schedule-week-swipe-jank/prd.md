# 修复左右切换周卡顿回归

## 目标

消除新版本课表松手左右切周时的明显停顿，保持既有滚动、缩放、课程显示和切周行为。

## 背景与证据

- 用户在 planning 通过移动端真机反馈确认：卡顿发生在**松手换周时**，不是拖动期间；顶栏切周作为对照。
- 用户已在 2026-10-11 批准本任务的规划摘要并授权实施；任务状态 `in_progress`。
- 当前 `master`，任务创建前工作区干净；最近课表修改 `ceef1b9`（`ScheduleTable.tsx:139–144` 的 `h-full` → `min-h-full`）解决旧 WebView 竖向滚动。本任务未撤销它，也**没有证据**表明该提交是本次性能回归来源。
- 生产构建、Chrome 155、412×731 CSS px、18 格合成课表、CPU 未降速的**基线**：左右各 3 次切周均有 672–824ms 主线程长任务，松手后最大帧间隔 1083–1317ms（`research/baseline-profile.json`）。
- CPU 采样把热点定位到 `ScheduleCourseCell.tsx` 的内容高度读取（`scrollHeight - clientHeight`），即课程格空间自适应测量的同步布局读取，而非 React 渲染或持久化（`research/baseline-profile.json.cpuprofile`）。

## 需求

- R1：用真实触摸性能循环与调用栈证据定位松手切周停顿原因，不凭源码猜测调动画参数。
- R2：消除不必要测量和布局阻塞，保持全部空间自适应规则：字段优先级、教室恒显、8–15px 字号、0.05 兜底阶梯、文字块居中与防溢出。
- R3：保留单指竖向滚动、缩放、取消、连续手势、学期边界回弹、关闭边缘切周开关及减少动效偏好行为。
- R4：不改变课程数据、颜色分配、周次边界、持久化格式或手势动画方向。

## 验收标准

- AC1（R1/R2）：相同合成课表、视口、引擎、未降速 CPU 下，左右各 3 次松手 400ms 窗口均无 ≥50ms 主线程长任务，最大帧间隔 ≤50ms；保留修复前后读数。4 倍 CPU 降速另作压力对照，不作为真机结论。
- AC2（R3/R4）：达标手势只切一周；不达标、取消或学期边界不误切；结束时无残留位移/透明度；顶栏对照正常。
- AC3（R2/R3）：字段/备注/单双周变化能重新适配；长课名和多视口、多缩放档位的字号及显隐无回归；竖向滚动可到第 12 节；`min-h-full` 兼容性保留。
- AC4（R1–R4）：相关回归测试、全量测试、类型检查、lint、构建及 WebView 产物检查通过；真实浏览器必须验证 DOM 测量。原生 WebView 环境不可用或用户设备未测时明确列出范围，不以桌面性能结论代替。

## 验收结果（2026-10-11）

- AC1 满足：修复后同一循环无 ≥50ms 长任务、最大帧间隔 33.5–50ms（多次复跑，`research/after-batch-cpu1.json`）；4 倍降速对照 73–134ms 长任务，仅作改善比例参考（`research/after-batch-cpu4.json`）。
- AC2 满足：每次循环内由脚本断言「一次手势只切一周、结束态 `idle`、内联 transform/opacity 为空」，6/6 通过。
- AC3 满足：三视口 × 1x/2x × 跨周的课程格适配断言 violations = 0（`research/cell-layout.*`）；`min-h-full` 与滚动链未改动，既有源码守卫与 `pnpm webview:check-css` 通过。
- AC4 部分满足：`pnpm test` 413 用例、`typecheck`、`lint`（0 problems）、`format:check`、`build`、`webview:check-css`、`test:android-assets` 全绿；**原生 WebView 与用户设备未复核**（沙盒只读 `/home/yetongy/.gradle` + 无 DNS，无法产出装本次改动的 APK），范围与原因见 `research/README.md` §4。

## 范围外

不重设计课表，不预先引入相邻周预渲染，不处理另一个多触点竖向滚动任务，不通过隐藏信息或修改字段换取速度，不发布版本、不自动提交。

## 风险与复盘

- 课程格测量还承担首帧与字体晚到纠偏，因此修复保留「挂载即入队 + 字体就绪补测」，只去掉重复与逐格读写交错。
- 本次把测量改成「内容依赖 + 共享队列批量执行」，代价是首帧比原来晚一个绘制帧才完成适配；首帧显示的是保守态（教师/备注 `hidden`），不会闪出被裁内容。
- 未闭环项：真机（Android WebView）与用户设备上的实际改善幅度仍未被测量，需在具备构建/安装环境时补做。
- 已确认事实、实验读数与未验证范围全部落库在 `research/README.md`。
