# 恢复课表目标配色

## Goal

恢复用户指定的旧版课表视觉：参考 `.trellis/spec/frontend/mobile-schedule-layout.md` 中的历史目标色板，让手机端与桌面端课程卡片都使用原目标颜色。

## Requirements

- 本周课程恢复 8 组平色背景与白色文字：`#87e5d4`、`#7bb7ef`、`#84aef7`、`#bcaaf5`、`#ee7c9b`、`#e7a0b3`、`#e98d78`、`#eab776`。
- 课程颜色恢复 `718812f` 中已有的分配规则：整学期 `courseId` 去重排序后依次分配色板档位；8 门以内不重色，同一课程跨周与刷新后同色。
- 非本周课程恢复按对应课程颜色淡化后的色板与白字。
- 常态描边恢复半透明白内描边；保留既有出勤状态表达和卡片布局行为。

## Acceptance Criteria

- [x] 本周课程主题与历史目标色值一致，标题和次要文字为白色层级。
- [x] 同一课程按历史顺序分配规则保持固定颜色；8 门以内不同课程不重色，非本周课程匹配该课程的淡化色。
- [x] 常态描边为半透明白色，缺勤 / 已上描边状态不受影响。
- [x] 手机端与桌面端使用同一组目标主题。
- [x] 变更限于课表配色相关代码，不改导入流程和布局。

## 补充排查（2026-10-08）

- 用户反馈不同课程共用同一颜色，并要求回退已有正确逻辑。
- `51f08a8` 恢复目标色板时误将 `718812f` 的顺序分配换成了更早的哈希取模。最小复现：课程号 `1001` 和 `1009` 都得到档位 0，即 `#87e5d4`。
- 本轮只恢复已有顺序分配与缺失映射的档位 0 兜底；保持目标主色、对应淡化色、白字和描边。
- 色板仍为 8 色，超过 8 门按历史规则循环复用，不扩展色板。
